# RentZal landing

Одностраничный лендинг по брендбуку RentZal. Реальные возможности продукта сверены с локальным проектом SNKI; сервер исходного продукта не изменён. Подробный разбор — в `../PROJECT_ANALYSIS.md`.

## Локальный запуск

Node.js 22.13+ и npm.

```sh
npm ci
npm run dev
```

Страница: http://127.0.0.1:3000

```sh
npm run build
npm start
```

Результат сборки — `dist/client`. Это статическая страница, сервер приложения и API для лендинга не нужны. Скрипт сборки содержит небольшой обход ошибки принудительного завершения Vinext на Windows; ненулевые коды ошибок сохраняются.

## Переход в продукт

`lib/rentzal.ts` содержит `publicUrl` и `localUrl`. Сейчас публичный адрес пуст, поэтому кнопка открывает пояснение и ссылку на локальный каталог `http://localhost:5173/slots`. После размещения продукта задайте `publicUrl` без завершающего слеша и пересоберите лендинг: кнопки станут прямыми ссылками в каталог.

## Контент и дизайн

- Палитра: #B9F227, #10161D, #F4F6F1; локальный Inter.
- Три оригинальных SVG сохранены в `public/brand` без изменения.
- Иллюстративная карточка не получает живые данные и не создаёт бронирования.
- Основные файлы: `app/page.tsx`, `app/globals.css`, `app/faq.tsx`, `app/product-link.tsx`.
- Фото и источники: `ASSET_CREDITS.md`.
- Приватное размещение Sites настроено через `.openai/hosting.json`.

Проверено в Chrome через Playwright: навигация, CTA, доступный диалог, закрытие Escape, FAQ, загрузка изображений, адаптивность 1440 / 390 / 320 px. Сценарии записи и оплаты основного приложения не запускались.
